# Search

Search finds what you are looking for across kb: the documents that best match, with the passage in each that matches best, your conversations, pages of kb and sections of this help. Documents match by meaning, not only by exact words, so a question or a description works as well as keywords. There are two ways into the same search: the search box at the top of the sidebar, and the **Search** page.

## Search from any page

The search box at the top of the sidebar is on every page. Press ⌘K (on a Mac) or Ctrl+K (on Windows and Linux) to jump into it.

1. Type a few letters. Matches appear below the box as you type, grouped by kind; **Pages** lists the pages of kb whose name contains what you typed, for example **Chat** when you type "chat".
2. Select a match, or move to it with the Up and Down arrow keys and press Enter, to open it.
3. Press Escape to close the list; press it again to empty the box.

**Documents** lists the documents that match by meaning, each once with the start of its best matching passage; see [Search your documents](#search-your-documents). **Conversations** lists your chats whose title or messages contain what you typed; see [Find a conversation](chat.md#find-a-conversation).

**Help** lists the sections of this manual whose heading or text contains every word you typed, sections whose heading matches first. Each shows the name of its help page and the matching text; selecting one opens the help page at that section. For example, typing "rename" lists **Rename a conversation**.

Each group shows its first five matches. To see all of them, select **See all results for …** at the bottom of the list, or press Enter without choosing a match.

While a group is still searching it shows a spinning circle and "Searching…"; if it can't be searched, it says why in that group; see [When search does not work](#when-search-does-not-work). The other groups still show their matches.

## See all results

The **Search** page lists every match, grouped the same way as below the search box and in the same order, so its first five matches in each group are the ones the box shows. It opens from **See all results for …**; you can also open it with **Search** in the sidebar, **Search** on the **Documents** page, or **Search documents** on the home page.

1. Type what you are looking for in the box at the top of the page.
2. Select **Search**, or press Enter.

The address of the page contains your search, so you can bookmark it, share it, or go back to earlier searches with the browser's Back button. Searching from the sidebar's box and from the page's own box leads to the same address and the same results.

## Search your documents

Type what you are looking for in either search box; matching documents appear under **Documents**. You get up to 20 documents, each once, the best match first. A document ranks by its best matching passage, so a document that matches in many places doesn't push others out. Each shows the document's title and the start of its best matching passage.

If no document matches, **Documents** says "No matches."; try other words. Only documents with the status **Ready** are searched.

## Open a passage in its document

Select a document under **Documents**. The document opens at its best matching passage and highlights it briefly, with the passages around it. See [Read the passages of a document](documents.md#read-the-passages-of-a-document).

## When search does not work

- "Search needs the Models service, which isn't available right now." under **Documents**: the language model kb uses to compare meaning can't be reached. The other groups still work. Check [Models](models.md) and try again later.
- "… isn't available right now." or "Couldn't search …": that group can't be searched at the moment; search again later.
- "Enter a search term" appears when you select **Search** on the **Search** page with an empty box.
