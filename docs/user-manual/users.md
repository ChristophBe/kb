# Users

The Users page lists everyone who has signed in to Knowcelium and lets platform admins designate other platform admins. It is only available to platform admins; other people don't see it in the sidebar.

## See the users

Open **Users** in the sidebar. The table lists each person's name and email address, and marks platform admins with a **Platform admin** badge. You are marked with **(you)**.

A person appears in the list once they have signed in to Knowcelium for the first time.

If you open the page without being a platform admin, Knowcelium says "Only platform admins can see the users."

## Make someone a platform admin

Select **Promote** in the person's row. They are a platform admin from then on and see the **Users** page after they reload Knowcelium.

## Remove a platform admin

1. Select **Demote** in the person's row.
2. Confirm with **Demote**.

The person is an ordinary user again. You can demote yourself too, as long as another platform admin remains; then the Users page closes for you.

The platform always keeps at least one admin: if you try to demote the last one, Knowcelium says "The platform needs at least one admin. Promote someone else first."
